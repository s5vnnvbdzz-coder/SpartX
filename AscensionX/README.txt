ASCENSIONX — GITHUB PAGES
========================

Live app:
https://s5vnnvbdzz-coder.github.io/SpartX/AscensionX/

Install:
1. Open the live app in Chrome or Edge.
2. Use the browser Install App option (or Add to Home Screen on mobile).
3. The app opens directly on Workout.

Data:
- Workout entries, profile, cycle and progression history are stored locally in this browser/device.
- Use Profile > Data & backup to export a JSON backup before changing devices or clearing browser data.
- Import a previously exported JSON backup from the same screen.

Deployment:
This app lives in the /AscensionX/ folder of the SpartX GitHub Pages repository.
Its service worker is scoped to /SpartX/AscensionX/ and does not control the SpartanX root app.
